# The-Breakfast-Bunch
CS 3354 Project
By Lyndsey and Alexa

# Overview
This project is a chess game built in Java Swing. It integrates backend chess logic, board state management, piece movement rules, and a playable interface.

# Features
- Full 8x8 chess board
- Legal move validation
- Captures
- Turn tracking
- Check and checkmate detection
- Undo move
- Save and load game state

# How to Run
1. Open the project in Eclipse.
2. Run `main.Main`.
3. Use the GUI to play by clicking a piece and then its destination square.
OR
1. Right click on Main.java
2. Hit Run Java
3. Use the GUI to play by clicking a piece and then its destination square.

# Project Structure
- `board` — board storage
- `game` — game flow and rule validation
- `gui` — chess interface
- `main` — program entry point
- `pieces` — chess piece movement rules
- `utils` — helper classes
